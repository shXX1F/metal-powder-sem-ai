# 生产校准与固定 20 图回归验收（2026-07-24）

## 1. 锁定配置

- 权重：`tos://tos-mlp-zgci/fxx/runs/maskrcnn_particle_final_calibrated_20260717.pth`
- 推理：整图与 640 px 切块融合，重叠 192 px，`score=0.62`，`mask=0.68`
- 圆度报告：原始掩膜 Crofton 4 方向周长，`Q=4*pi*A/P^2`，`C=sqrt(Q)`
- 球形判定：`0.75*C_open3 + 0.25*C_smooth3 >= 0.9490`
- 粒径：最大 Feret 径，分位数采用 lower-rank
- 团聚判定：0.30 um、接触弧占比 0.09、掩膜重叠占比 0.03、至少 3 颗成组

机器可读配置见 `docs/production_calibration_20260724.json`。

## 3. 圆度与球形率结论

轮廓周长、亚像素周长、Crofton 2 方向以及 3x3 形态学圆度均完成同条件比较。原始 Crofton 在报告 Q/C 上误差最低，线性和二次经验校正的留一图误差反而增加，因此不加入报告计算。

球形分类单独采用形态学组合特征。该方法在 20 次留一图验证中均选择阈值 0.9490，留一图球形率 MAE 为 4.267 个百分点，稳定优于旧的原始 Crofton 阈值方案。

## 4. 团聚判定结论

203 个人工复核颗粒对中含 131 个正例和 72 个负例。校准后的颗粒对精确率为 0.9690、召回率为 0.9542、F1 为 0.9615、平衡准确率为 0.9493。该结果支持颗粒对与连通组判定，但仍需新增图像级团聚率真值，才能报告无偏的 `P_agglom` MAE。

## 5. 验收边界

固定 20 图参与过参数选择，适合回归与工程验收，不应被描述为完全独立测试集。正式对外交付前，应再锁定一批从未参与训练和校准的新图，按同一配置一次性验收。
