# 金属粉末 SEM AI 最终校准与验收记录（2026-07-17）

## 1. 最终生产方案

- 权重：`maskrcnn_particle_final_calibrated_20260717.pth`，由旧稳定权重 92.5% 与 Round4 epoch 42 权重 7.5% 进行参数融合。
- 推理：综合识别，`score=0.62`、`mask=0.68`，普通整图与 640 px 切块结果合并，重叠 192 px，启用 tile ownership 去重。
- 圆形度/球形度：Crofton 周长，`Q=4*pi*A/P^2`，`C=sqrt(Q)`。
- 球形颗粒率：参考软件按 `C>=0.90`，系统经留一图校准后按 `C>=0.9075`。
- 粒径：最大 Feret 径；D5/D10/D50/D90/D95 使用参考软件一致的 lower-rank 分位数。

机器可读配置见 `docs/production_calibration_20260717.json`。

## 3. 相对旧稳定权重的改进

与旧稳定权重在相同固定集上的已调参基线相比，最终模型的综合排序得分由 `0.7481` 降至 `0.7266`（越低越好）。主要改善来自圆形度、球形度和粒径统计；颗粒数误差基本持平。

- 圆形度与球形度改用 Crofton 周长，并通过逐颗粒匹配验证。
- 修复了系统球形阈值与参考阈值共用同一参数的评估错误，避免“参考答案随系统参数变化”。
- 球形阈值经过 20 折留一图验证，每一折都选择 `0.9075`。
- 最大 Feret 径在 20 图上平均粒径 MAE 为 `1.303 um`，优于外接框最大径的 `1.539 um`。
- 线性和二次校正均在留一图测试中变差，因此没有加入容易过拟合的经验修正。

## 4. 验收边界

固定 20 图已经参与模型和参数选择，适合做回归基准，但不能再作为完全无偏的最终测试集。正式验收前应新增一批不参与任何调参的锁定测试图，保持 SEM 倍率、材料、颗粒密度和粒径范围分层覆盖。

团聚体、空心粉目前缺少可靠逐颗粒真值，相关结果仍应视为辅助指标。

## 5. 2026-07-18 团聚率工程优化

- 数量与面积公式不变：P_agglom = N_agglom/N_total，P_area = A_agglom/A_total。
- 团聚成员不再只按固定像素距离判断；系统使用 SEM 标尺将 0.30 um 工程默认容差换算为像素。
- 邻近颗粒还必须满足接触弧占比或掩膜重叠占比条件，降低正常密堆、点接触造成的误判。
- 默认至少 3 个颗粒通过强接触边形成连通组，才计入团聚颗粒。
- Excel 与 CSV 会导出每个候选颗粒对的间隙、接触弧、重叠占比和判定原因，可人工填写 manual_truth。
- 新增 tools/calibrate_agglomeration_thresholds.py，用人工真值搜索物理间隙、接触弧和重叠阈值。

当前 0.30 um、0.12 接触弧占比和 0.03 重叠占比是保守工程初值，不是团聚率验收阈值。正式验收必须覆盖不同倍率与材料的正负团聚真值，并在新的锁定测试图上报告团聚率 MAE。
